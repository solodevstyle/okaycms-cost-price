# SoloDevMan CostPrice

Модуль для OkayCMS, який додає собівартість товарних варіантів і звіт по прибутку з урахуванням щомісячних витрат.

## Можливості

- поле `Собівартість` для варіантів товару;
- збереження собівартості в покупках замовлення;
- додаткова колонка доходу в стандартному звіті продажів;
- окремий звіт `Прибуток та витрати`;
- категорії витрат;
- внесення витрат по місяцях;
- розрахунок чистого прибутку: прибуток виконаних/відправлених замовлень мінус витрати за вибраний період.

## Встановлення

1. Скопіюйте папку модуля в:

   ```text
   Okay/Modules/SoloDevMan/CostPrice
   ```

2. В адмін-панелі OkayCMS відкрийте розділ модулів.
3. Знайдіть `SoloDevMan / CostPrice` і встановіть модуль.
4. Видайте менеджеру право доступу `sdm_cost_price`.

Під час встановлення модуль додає поле `cost_price` до варіантів і покупок, а також створює таблиці для категорій витрат і витрат по місяцях.

## Використання

Після встановлення в адмін-панелі з'явиться пункт `Прибуток та витрати`.

1. Заповніть собівартість у товарах або у списку товарів.
2. Створіть категорії витрат.
3. Додайте витрати для потрібних місяців.
4. Відкрийте звіт `Прибуток та витрати` і виберіть період.

Якщо в замовленні немає збереженої собівартості, звіт спробує взяти поточну собівартість варіанта товару. Якщо собівартість не вказана і там, модуль покаже попередження зі списком товарів.

## Сумісність

Модуль розрахований на OkayCMS з системою модулів `Okay\Modules` і стандартними сутностями `VariantsEntity`, `PurchasesEntity`, `OrdersEntity`, `ReportStatEntity`.
